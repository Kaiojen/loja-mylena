# Prompt para Dashboard da My Dream

Use este prompt em uma IA de planilhas, Google Sheets, Excel, Notion ou Airtable.

```text
Crie um dashboard operacional moderno, simples de usar e visualmente limpo para a My Dream Artes Gráficas, uma loja de artes digitais que vende convites digitais, convites interativos, kits digitais para festa/casamento e artes personalizadas do zero.

Contexto do negócio:
- Todos os produtos são digitais. Não existe envio físico.
- A venda principal acontece pelo WhatsApp.
- O tráfego inicial virá principalmente de Facebook Ads/Instagram Ads, com medição da Meta já configurada.
- Os pacotes principais são:
  - Convite digital simples: R$ 49,90
  - Convite interativo: R$ 79,90
  - Kit digital festa/casamento: R$ 129,90 a R$ 189,90
  - Personalizado do zero: a partir de R$ 149,90
- O objetivo é controlar leads, pedidos, produção, faturamento, prazos, desempenho dos anúncios e lucro estimado.

Quero que você monte uma estrutura de dashboard com abas/tabelas conectadas e campos padronizados:

1. Leads
Campos: data de entrada, nome da cliente, WhatsApp, origem do lead, campanha/anúncio, modelo de interesse, pacote desejado, status do atendimento, responsável, observações, próximo contato, valor estimado, virou pedido? sim/não.
Status sugeridos: novo, aguardando resposta, briefing recebido, orçamento enviado, pagamento pendente, convertido, perdido.

2. Pedidos
Campos: número do pedido, data da venda, nome da cliente, WhatsApp, pacote, modelo escolhido, valor vendido, forma de pagamento, status do pagamento, status do pedido, data limite, data de entrega, quantidade de ajustes, link do arquivo/arte, observações.
Status sugeridos: aguardando dados, em criação, prévia enviada, em ajuste, finalizado, entregue, atrasado, cancelado.

3. Briefing e Produção
Campos: pedido relacionado, tipo de evento, nome(s), data do evento, horário, local, paleta, tema, referências enviadas, texto do convite, itens do kit, prioridade, prazo combinado, status de criação.

4. Financeiro
Campos: data, tipo, descrição, pedido relacionado, receita, despesa, canal, forma de pagamento, taxa, lucro estimado.
Categorias de despesa: tráfego pago, ferramenta/design, domínio/site, taxa de pagamento, outros.

5. Tráfego Pago
Campos: data, plataforma, campanha, conjunto, anúncio, investimento, impressões, alcance, cliques, conversas iniciadas, leads qualificados, vendas, faturamento gerado.
Calcular automaticamente: CPC, CPL, custo por conversa, custo por venda, taxa de conversão lead/venda, ROAS, lucro estimado.

6. Catálogo e Pacotes
Campos: nome do modelo/pacote, categoria, preço base, prazo padrão, itens inclusos, ajustes inclusos, mensagem padrão para WhatsApp, status ativo/inativo.

7. Dashboard Principal
Crie uma página inicial com cards e gráficos:
- Faturamento do mês
- Lucro estimado
- Total investido em tráfego
- Leads recebidos
- Pedidos fechados
- Taxa de conversão
- Ticket médio
- CPL
- Custo por venda
- ROAS
- Pedidos atrasados
- Pedidos por status
- Vendas por pacote
- Vendas por origem
- Evolução diária/semanal de leads, vendas e faturamento

Regras e automações desejadas:
- Usar menus suspensos para status, origem, pacote e forma de pagamento.
- Destacar pedidos atrasados em vermelho ou alerta discreto.
- Destacar próximos prazos em até 24 horas.
- Calcular ticket médio, conversão e lucro automaticamente.
- Permitir filtro por mês, campanha, pacote e status.
- Ter uma visualização simples para uso diário no celular.
- Ter visual moderno, com cards de KPI, gráficos limpos e cores suaves, sem parecer uma planilha comum.

Entregue:
1. A estrutura das abas.
2. Os nomes exatos das colunas.
3. As fórmulas principais.
4. Sugestões de gráficos.
5. Uma orientação curta de como usar o dashboard todo dia.
```
