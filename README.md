# My Dream Artes Gráficas

Landing page em React, TypeScript e Vite para catálogo de convites digitais, papelaria personalizada e artes exclusivas.

## Rodar localmente

```bash
npm install
npm run dev
```

Acesse `http://127.0.0.1:5173/`.

## Build de produção

```bash
npm run build
```

O resultado é gerado em `dist/`.
